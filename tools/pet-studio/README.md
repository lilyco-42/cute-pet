# 角色工作台：验证版

目标：用户上传授权 PNG 部件 → 调整位置/缩放/层级 → 即时预览 → 导出 PNG 与可编辑 JSON。图像始终在浏览器本地处理；可选地把文字指令和图层元数据发给用户配置的 OpenAI 兼容模型，让模型只建议位置、缩放或显隐变化。`petpack.html` 是独立的实验性打包页：将用户已有的 5 条透明 PNG 横向动作帧带切分、播放预览并导出 `.petpack` ZIP，不负责生成动作。

这是独立的素材编辑原型，尚未接入 lain42 登录、积分账本、原生 cute-pet manifest 或 let-gal 导出，也不是 Live2D 自动绑定工具。`.petpack` 按 `redniu123/pet-player` 的 schema v1 做实验性兼容；GitHub Actions 已使用目标仓库固定提交 `342999f` 的官方 Python 校验器验证导出包。该检查只证明包结构与资源符合该格式，尚未在桌面播放器 UI 中完成导入验收，也不代表它是通用标准。模型 API Key 只在当前页面使用，不写入存储；AI 不会收到 PNG 像素。默认 API 地址的跨域设置与线上模型兼容性尚未验证。
