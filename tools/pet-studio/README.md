# 角色工作台：验证版

目标：用户上传授权 PNG 部件 → 调整位置/缩放/层级 → 即时预览 → 导出 PNG 与可编辑 JSON。直接打开 index.html，所有处理留在浏览器，不调用模型、不上传文件。

这是独立的素材编辑原型，尚未接入原生 cute-pet manifest，也不是 Live2D 自动绑定工具。先验证创作者能否做出愿意使用的作品，再接入 AI 与游戏导出。
